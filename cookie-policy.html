Current setup at a glance

The Window Match front end does not currently set advertising or analytics cookies. It uses one essential localStorage entry to remember that the privacy notice has been reviewed on the current browser.

Choosing “Accept” does not activate advertising tracking. All three choices currently save only an essential preference value.

Cookies and browser storage

A cookie is a small text record a website or service may place in a browser. Similar technologies include local storage, session storage, pixels, tags and software-development tools that remember information or send technical events.

This policy describes technologies used by the Window Match website itself and limited technologies that may be required by hosting, security and email infrastructure. It should be read with the Privacy Policy.

Hosting and security technologies

A hosting, content-delivery, firewall or security provider may process standard request information or use strictly necessary cookies or similar controls to deliver pages, balance traffic, prevent automated abuse and maintain security. The precise technology can depend on the production host selected by Window Match.

These infrastructure controls should be configured for operational and security purposes, not behavioral advertising. Server logs may include an IP address, request time, requested page, browser details and security events even when no browser cookie is set.

Technologies we do not currently use

The current website code does not enable:

  • third-party advertising cookies;
  • cross-site behavioral advertising pixels;
  • remarketing audiences;
  • social-media tracking widgets;
  • session-replay tools;
  • third-party analytics cookies; or
  • profiling based on activity across unrelated websites.

If optional analytics, advertising or personalization technologies are added later, this policy and the preference interface must be updated before use, and any consent or opt-out required by applicable law must be provided.

Change your privacy preferences

Use the button below to remove the saved preference and reopen the privacy notice. Selecting a choice creates a new value on the current browser only; it does not update other browsers or devices.

If storage is unavailable or blocked, the website can still be used, but the notice may appear again because the browser cannot remember your choice.

Browser-level controls and preference signals

Most browsers allow you to inspect, block or delete cookies and local website data. Deleting site data removes the saved Window Match preference and may cause the notice to reappear.

Browsers may also send Do Not Track or Global Privacy Control signals. The current front end does not use cross-site advertising trackers or sell browser activity through cookies, so no optional tracker is activated regardless of the signal. If future processing requires recognition of an opt-out preference signal, Window Match will update its controls as required.
